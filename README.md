# Web Monitor Starter

Универсальный стартовый репозиторий для проектов, где нужно регулярно обходить сайты, собирать цены/наличие/параметры, складывать историю в базу и показывать результат в админке.

Подходит для:
- мониторинга цен анализов и лабораторий;
- мониторинга товаров и маркетплейсов;
- мониторинга конкурентов;
- отслеживания наличия / скидок / изменений страниц;
- любых задач вида: `источник -> сбор -> нормализация -> история -> сравнение -> уведомления`.

## Почему не fork одного price-tracker проекта

Задачи похожи, но домены разные: анализы, товары, услуги, пропуска, штрафы, каталоги. Поэтому лучше иметь собственный шаблон:

- `apps/admin` — CRM/админка на Next.js;
- `apps/worker` — crawler/worker на TypeScript;
- `packages/db` — SQL-миграции Supabase/Postgres;
- `packages/shared` — общие типы, нормализаторы, схемы;
- `docs` — архитектура, roadmap, промты для Cursor.

## Стек

- Next.js App Router
- TypeScript
- Supabase/Postgres
- Crawlee + Cheerio/Playwright
- Tailwind
- pnpm workspaces

## Быстрый старт

```bash
pnpm install
cp .env.example .env
```
